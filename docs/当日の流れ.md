# 当日の流れ

この資料は、学園祭の2日間に「プログラミング体験会」のスタッフが行うことをまとめたものです。

## 1. 来場者の案内

1. 来場者を、来た順番に制作PCへ案内する。
2. 制作PCは8台使用する。
3. 1人あたりの体験時間は未定とし、当日のスタッフが管理する。

## 2. 体験中

スタッフは、来場者が次の順番で体験を進められるように案内する。

1. ホーム画面で「自由にお絵かき」または「イニャーの塗り絵」を選ぶ。
2. マウスを使ってキャラクターを描く。
3. タッチ操作は使用しない。
4. 「次へ」を押してプログラミング画面へ進む。
5. Blocklyのブロックを使い、動きやセリフを設定する。
6. 使用するブロックは最大5個までとする。
7. 「放流する」を押し、作成したキャラクターを大画面へ送る。
8. 完了画面の表示後、約5秒でホーム画面へ戻る。

お絵かき画面からプログラミング画面へ進んだあとは、前の画面には戻れません。

## 3. トラブルが発生した場合

トラブルが発生した場合は、気付いたスタッフが各自で対応します。
具体的な対応方法は、現時点では決まっていません。
